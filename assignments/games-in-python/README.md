
# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a classic Hangman word-guessing game in Python that practices string handling, loops, conditionals, and user input.

## 📝 Tasks

### 🛠️ Create the Hangman Game

#### Description

Write a Python program that lets a player guess letters to uncover a hidden word before they run out of attempts.

#### Requirements

Completed program should:

- Randomly select a word from a predefined list
- Prompt the player to guess letters one at a time
- Display the current word progress using underscores and revealed letters
- Track and display the number of incorrect guesses remaining
- End the game with a win message when the word is guessed or a lose message when attempts are exhausted

### 🛠️ Add Replay and Input Validation

#### Description

Improve the game loop by allowing replay and rejecting invalid input.

#### Requirements

Completed program should:

- Ask the player if they want to play again after each game
- Accept only single-letter guesses and ignore invalid input
- Prevent repeated letter guesses from counting as new incorrect attempts
- Show the final result and replay prompt clearly
