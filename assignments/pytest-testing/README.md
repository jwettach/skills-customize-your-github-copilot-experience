# 📘 Assignment: pytest Testing

## 🎯 Objective

Learn how to write and run automated tests with pytest so you can verify Python code behavior and catch bugs early.

## 📝 Tasks

### 🛠️ Implement Utility Functions

#### Description

Write a set of Python functions that perform common operations, and prepare them for test-driven development.

#### Requirements

Completed program should:

- Implement functions in `starter-code.py`
- Include at least three different functions with clear input/output behavior
- Keep function behavior deterministic and easy to test
- Use docstrings or comments to explain each function

### 🛠️ Write pytest Test Cases

#### Description

Create pytest tests that verify the utility functions work correctly across normal and edge cases.

#### Requirements

Completed program should:

- Use `pytest` to run the tests
- Cover valid cases and invalid or boundary inputs
- Assert expected return values and error behavior when appropriate
- Include at least one test for each function

### 🛠️ Run tests and fix failures

#### Description

Run pytest locally, review test output, and update your implementation until all tests pass.

#### Requirements

Completed program should:

- Run `pytest` successfully with no failures
- Show passing test output for all test cases
- Demonstrate a simple developer workflow with code + tests
